<p>When managing a website, it's essential to ensure that all variations of your domain URL consistently redirect to your desired primary URL. In this case, the primary URL is <code>https://example.com</code>. Proper redirection not only provides a smoother user experience but also improves SEO by consolidating domain authority.</p><p>Imagine you have domain <code>example.com</code> and your boss ask you to use <code>https://example.com</code> as the main URL, not the one with <code>www</code>.</p><p>In this guide, we'll walk you through testing common URL variations to ensure that they correctly redirect to your primary URL (<code>https://example.com</code>). The common scenarios we'll focus on are:</p><ul><li>Redirecting <code>http://example.com</code> to <code>https://example.com</code></li><li>Redirecting <code>http://www.example.com</code> to <code>https://example.com</code></li><li>Redirecting <code>https://www.example.com</code> to <code>https://example.com</code></li></ul><h3 id="step-1-verify-the-redirection-setup">Step 1: Verify the Redirection Setup</h3><p>First, you need to set up your web server (Apache, Nginx, etc.) to properly handle these redirections. Read <a href="__GHOST_URL__/best-practices-for-setting-up-a-web-domain-example-com-with-https-and-redirects/" rel="noreferrer">this article related to that</a>.</p><h3 id="step-2-test-redirection-using-browser-tools">Step 2: Test Redirection Using Browser Tools</h3><p>You can test one-by-one of your URLs on the browser, and all should go to https://example.com</p><h3 id="step-3-use-curl-for-cli-testing">Step 3: Use Curl for CLI Testing</h3><p>For a more detailed look at the redirection process, especially for automated or server-side testing, you can use <code>curl</code> from the command line. The <code>curl</code> tool allows you to see HTTP headers and the steps of redirection.</p><p>Test redirection from <code>http://example.com</code>, run this <code>curl -I -L http://example.com</code></p><p>Test redirection from <code>http://www.example.com</code>, run this <code>curl -I -L http://www.example.com</code></p><p>Test redirection from <code>https://www.example.com</code>, run this <code>curl -I -L https://www.example.com</code></p><h4 id="expected-output">Expected Output:</h4><p>When you run these commands, you should see a sequence of <code>301</code> or <code>302</code> status codes leading to the final destination URL. For example:</p><pre><code>HTTP/1.1 301 Moved Permanently
Location: https://example.com/
</code></pre><p>This indicates that the redirection is working as expected.</p><h3 id="step-4-use-online-tools">Step 4: Use Online Tools</h3><p>There are many tools for doing redirection test on the internet.
