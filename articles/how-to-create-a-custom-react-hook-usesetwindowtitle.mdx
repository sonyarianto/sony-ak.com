<p>In the world of <strong>React</strong>, <strong>custom hooks</strong> have become an essential tool for writing <strong>clean</strong>, <strong>reusable</strong>, and <strong>modular logic</strong>. They allow developers to <strong>extract repeated behavior</strong> into a simple function, enhancing both readability and maintainability.</p><p>One interesting use case is managing the <strong>browser window title</strong> (i.e., <code>document.title</code>). Imagine you want to dynamically set the page’s title based on user navigation, data fetching, or any specific action. Instead of cluttering your components with repetitive <code>useEffect</code> calls, you can <strong>encapsulate this logic into a custom hook</strong>. Let’s call it <code>useSetWindowTitle</code>.</p><hr><h2 id="what-is-usesetwindowtitle"><strong>What is <code>useSetWindowTitle</code>?</strong></h2><p><code>useSetWindowTitle</code> is a <strong>custom React hook</strong> that serves as a wrapper for <strong><code>useEffect</code></strong>, designed to <strong>update the browser’s window title</strong> dynamically. It simplifies what would otherwise be <strong>boilerplate code</strong> in every component.</p><h3 id="%E2%9C%A8-key-features">✨ <strong>Key Features</strong></h3><ul><li><strong>Encapsulation of logic</strong>: Handles title updates in one place.</li><li><strong>Reusability</strong>: Import and use in any component with a single call.</li><li><strong>Clean code</strong>: Keeps components focused on UI rather than browser behaviors.</li><li><strong>Restores original title</strong> (optional): Ensures a component can clean up after itself.</li></ul><hr><h2 id="%F0%9F%9B%A0%EF%B8%8F-how-to-build-usesetwindowtitle">🛠️ <strong>How to Build <code>useSetWindowTitle</code></strong></h2><p>Here’s a <strong>complete implementation</strong> of <code>useSetWindowTitle</code>:</p><pre><code class="language-jsx">import { useEffect } from 'react';

function useSetWindowTitle(title) {
  useEffect(() =&gt; {
    // Save the original title
    const originalTitle = document.title;

    // Update the window title
    document.title = title;

    // Cleanup: Restore original title when component unmounts
    return () =&gt; {
      document.title = originalTitle;
    };
  }, [title]); // Run effect when 'title' changes
}

export default useSetWindowTitle;
</code></pre><p>This function:</p><ul><li><strong>Takes a <code>title</code> parameter</strong> representing the new window title.</li><li><strong>Saves the original title</strong> so it can be restored later.</li><li><strong>Updates <code>document.title</code></strong> whenever the <code>title</code> argument changes.</li><li><strong>Cleans up on unmount</strong>, restoring the previous title to avoid unexpected changes.</li></ul><hr><h2 id="%F0%9F%9A%80-how-to-use-it">🚀 <strong>How to Use It</strong></h2><p>Here’s an example of how you might use <code>useSetWindowTitle</code> in a React component:</p><pre><code class="language-jsx">import React from 'react';
import useSetWindowTitle from './useSetWindowTitle';

function ProfilePage() {
  useSetWindowTitle("User Profile");

  return &lt;h1&gt;Welcome to your profile!&lt;/h1&gt;;
}

export default ProfilePage;
</code></pre><p>Every time <code>ProfilePage</code> is mounted, the window title changes to <strong>"User Profile"</strong>. When you navigate away, the previous title is restored.</p><hr><h2 id="%F0%9F%94%8E-why-use-a-custom-hook-for-this">🔎 <strong>Why Use a Custom Hook for This?</strong></h2><p>You might wonder: <em>"Why not just put <code>useEffect</code> directly in the component?"</em> While that works, <strong>custom hooks offer several advantages</strong>:</p><ul><li><strong>DRY Principle</strong>: Avoid repeating the same logic across multiple components.</li><li><strong>Testability</strong>: It’s easier to test a hook’s logic in isolation.</li><li><strong>Organization</strong>: Keeps components focused on rendering and user interaction.</li><li><strong>Scalability</strong>: When multiple components need the same behavior, simply call the hook.</li></ul><hr><h2 id="%E2%9A%A0%EF%B8%8F-things-to-consider">⚠️ <strong>Things to Consider</strong></h2><ul><li><strong>Always use the <code>use</code> prefix</strong> for custom hooks to let React recognize them as hooks.</li><li><strong>Follow the rules of hooks</strong>: Only call hooks at the top level of your components, not inside loops or conditionals.</li><li><strong>Dependency management</strong>: If you plan to depend on multiple variables to control the title, you can expand the hook’s dependency array.</li><li><strong>SEO implications</strong>: Remember that <strong><code>document.title</code> is a client-side change</strong>. Search engines don’t necessarily see it if they don’t render JavaScript.</li><li><strong>React Router integration</strong>: You can combine this with <strong>React Router</strong> to set titles based on routes.</li></ul><hr><h2 id="%F0%9F%93%9D-finally">📝 <strong>Finally</strong></h2><p>The <code>useSetWindowTitle</code> hook is a <strong>simple yet powerful example</strong> of how custom hooks can <strong>clean up repetitive logic</strong>, <strong>enhance readability</strong>, and <strong>improve maintainability</strong>. Whether you’re working on a small side project or a large-scale application, this approach can <strong>save you time</strong> and <strong>reduce errors</strong>.</p><p>If you haven’t embraced <strong>custom hooks</strong> yet, this might be the perfect reason to start.</p><h3 id="support-us">Support Us</h3>
