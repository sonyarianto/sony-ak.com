<p>A <strong>numeric literal</strong> in JavaScript is a direct representation of a number in the code. It is a fixed value (constant) that represents a number without requiring any computation or processing. Numeric literals can represent different types of numbers, including:</p><ol><li><strong>Integer literals</strong>: Whole numbers without any fractional or decimal part.</li></ol><p>Example: <code>42</code>, <code>0</code>, <code>-100</code></p><ol><li><strong>Floating-point literals</strong>: Numbers that have a fractional part, written with a decimal point.</li></ol><p>Example: <code>3.14</code>, <code>0.5</code>, <code>-2.718</code></p><ol><li><strong>Exponential notation</strong>: A way to represent very large or very small numbers using a base and exponent (scientific notation).</li></ol><p>Example: <code>1e3</code> (represents <code>1000</code>), <code>2.5e-4</code> (represents <code>0.00025</code>)</p><h3 id="examples-of-numeric-literals">Examples of numeric literals:</h3><ul><li>Integer: <code>100</code></li><li>Negative integer: <code>-50</code></li><li>Floating-point: <code>12.34</code></li><li>Exponential: <code>5e6</code> (equivalent to <code>5000000</code>)</li></ul><h3 id="special-cases">Special Cases:</h3><ul><li><strong>Hexadecimal (base 16)</strong>: Numbers starting with <code>0x</code> represent hexadecimal values.<ul><li>Example: <code>0xFF</code> (255 in decimal)</li></ul></li><li><strong>Binary (base 2)</strong>: Numbers starting with <code>0b</code> represent binary values.<ul><li>Example: <code>0b1010</code> (10 in decimal)</li></ul></li><li><strong>Octal (base 8)</strong>: Numbers starting with <code>0o</code> represent octal values.<ul><li>Example: <code>0o77</code> (63 in decimal)</li></ul></li></ul><p>Numeric literals are different from <strong>number objects</strong>, which are created using the <code>Number</code> constructor (e.g., <code>new Number(5)</code>), though typically you use numeric literals in most cases for efficiency.</p><h3 id="is-1-numeric-literal">Is <code>1.</code> numeric literal?</h3><p>In JavaScript, <code>1.</code> is considered a <strong>numeric literal</strong>. It represents the number <code>1</code>, with the dot <code>.</code> indicating that the number can have a fractional part. Although <code>1.</code> is equivalent to <code>1</code>, <strong>the trailing dot ensures that JavaScript understands it as a floating-point number</strong>.</p><p>In this context, the dot doesn't change the value, but it allows for calling methods like <code>toString()</code> directly on the number. The second dot, as in <code>1..toString()</code>, is used to call the method.</p><p>So, <code>1.</code> is a valid numeric literal, and it's a shorthand way to write the floating-point number <code>1.0</code>. You can also use <code>1.0</code> or simply <code>1</code> to represent the same value.</p><p>Hope it helps.</p><h3 id="support-us">Support Us</h3>
