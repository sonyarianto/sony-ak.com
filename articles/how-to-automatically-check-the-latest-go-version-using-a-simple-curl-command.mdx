<p>In this article, we'll walk you through a simple way to automatically check the latest stable Go version directly from the official <a href="https://go.dev/dl/" rel="noopener">Go download page</a>. We'll do this using a combination of <code>curl</code> and <code>grep</code> commands, which fetch and filter the version information from the website. Here's how it works.</p><h3 id="command">Command</h3><p>Below is the complete command that checks and retrieves the latest stable version of Go for the Linux <code>amd64</code> architecture:</p><pre><code class="language-bash">curl -s https://go.dev/dl/ | grep -oP 'go[0-9]+\.[0-9]+\.[0-9]+\.linux-amd64\.tar\.gz' | head -n 1 | grep -oP 'go[0-9]+\.[0-9]+\.[0-9]+'
</code></pre><p>Output</p><pre><code>go1.23.1</code></pre><p>Let's break down each part of the command:</p><ol><li><code><strong>curl -s https://go.dev/dl/</strong></code>: This part sends an HTTP request to the Go download page and retrieves the raw HTML content of the page. The <code>-s</code> flag ensures that <code>curl</code> runs in "silent" mode, suppressing unnecessary progress information and errors.</li><li><code><strong>grep -oP 'go[0-9]+\.[0-9]+\.[0-9]+\.linux-amd64\.tar\.gz'</strong></code>: The output from <code>curl</code> is piped to <code>grep</code>, which looks for a specific pattern: <code>goX.Y.Z.linux-amd64.tar.gz</code>. This regular expression (<code>regex</code>) matches Go versions that follow the format <code>goX.Y.Z</code>, where <code>X</code>, <code>Y</code>, and <code>Z</code> are version numbers. The <code>-o</code> flag tells <code>grep</code> to output only the parts of the input that match the pattern, and the <code>-P</code> flag allows the use of Perl-compatible regular expressions.</li><li><code><strong>head -n 1</strong></code>: Since there may be multiple version entries listed, this command ensures that only the first match (typically the latest stable release) is selected. <code>head</code> outputs the first line of the results.</li><li><code><strong>grep -oP 'go[0-9]+\.[0-9]+\.[0-9]+'</strong></code>: The result from the first <code>grep</code> is then passed to another <code>grep</code> command to strip away the <code>linux-amd64.tar.gz</code> part of the filename, leaving only the version number in the form <code>goX.Y.Z</code>.</li></ol><p>This approach allows you to automate checking for new versions of Go in your scripts or as part of your update routines.</p><h3 id="finally">Finally</h3><p>By using this simple combination of <code>curl</code>, <code>grep</code>, and <code>head</code>, you can quickly and efficiently check the latest Go version available for download. This method is especially useful for automation in CI/CD pipelines or for anyone who wants to stay up-to-date with the latest Go releases without manually visiting the Go website.</p><p>Hope it helps.</p><h3 id="support-us">Support Us</h3>
