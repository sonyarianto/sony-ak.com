<p>When building multilingual applications or websites, <strong>handling language codes correctly</strong> is essential—not just for translation, but also for <strong>date formatting</strong>, <strong>number formatting</strong>, <strong>sorting</strong>, and <strong>user experience personalization</strong>.</p><p>Among the available standards, <strong>BCP 47</strong> (Best Current Practice 47) has emerged as the <strong>de facto standard</strong> for representing <strong>language and regional information</strong> in modern software systems.</p><hr><h2 id="%F0%9F%A7%A9-what-is-bcp-47">🧩 What is BCP 47?</h2><p><strong>BCP 47</strong> is a formal specification by the <strong>IETF (Internet Engineering Task Force)</strong>. It defines the <strong>syntax for language tags</strong>, which identify human languages in a format like:</p><pre><code>language-region (e.g., en-GB, de-DE, fr-CA)
</code></pre><p>These tags combine <strong>ISO language codes</strong> (from ISO 639) with <strong>country codes</strong> (from ISO 3166), and sometimes <strong>additional variants or scripts</strong>.</p><hr><h2 id="%F0%9F%94%A4-components-of-a-bcp-47-tag">🔤 Components of a BCP 47 Tag</h2><p>A typical BCP 47 tag looks like this:</p><pre><code>[language code]-[script code]-[region code]-[variant]
</code></pre><p>But most applications only need the <strong>language</strong> and <strong>region</strong> parts:</p><ul><li><code>**en-GB**</code> → English, as used in the United Kingdom</li><li><code>**de-DE**</code> → German, as spoken in Germany</li><li><code>**fr-CA**</code> → French, Canadian variant</li><li><code>**zh-Hans-CN**</code> → Chinese, Simplified script, in China</li><li><code>**sr-Cyrl-RS**</code> → Serbian, Cyrillic script, in Serbia</li></ul><hr><h2 id="%E2%9C%85-why-use-bcp-47-instead-of-just-iso-codes">✅ Why Use BCP 47 Instead of Just ISO Codes?</h2><p>Here’s why <strong>BCP 47</strong> is better than just <code>en</code>, <code>de</code>, or <code>fr</code>:</p>

<p>Example:<br><code>en-US</code> → <strong>"color", "center", "organize"</strong><br><code>en-GB</code> → <strong>"colour", "centre", "organise"</strong></p><hr><h2 id="%F0%9F%9B%A0%EF%B8%8F-where-bcp-47-is-used">🛠️ Where BCP 47 is Used</h2><ul><li><strong>Web development</strong>:<br>HTML supports <code>lang="en-GB"</code> for screen readers and search engines.</li><li><strong>APIs</strong>:<br>Headers like <code>Accept-Language: fr-CA</code> inform the server of the client’s preferred language/region.</li><li><strong>CMS and Translation Systems</strong>:<br>Tools like <strong>gettext</strong>, <strong>Laravel</strong>, <strong>Symfony</strong>, and <strong>Next.js i18n</strong> use BCP 47 tags for locale switching.</li><li><strong>Mobile apps</strong>:<br>Both <strong>iOS</strong> and <strong>Android</strong> use BCP 47 tags for regional settings.</li></ul><p><strong>JavaScript</strong>:<br>The <code>Intl</code> object uses BCP 47 for locale-sensitive operations:</p><pre><code class="language-js">new Intl.DateTimeFormat('de-DE').format(new Date())
</code></pre><hr><h2 id="%F0%9F%94%84-fallback-and-negotiation">🔄 Fallback and Negotiation</h2><p>If a specific tag like <code>en-NZ</code> isn’t available, systems can fall back to:</p><ul><li><code>en-AU</code> (close regional variant)</li><li><code>en</code> (generic English)</li></ul><p>You should design your system to support <strong>graceful fallback</strong> to avoid missing translations.</p><hr><h2 id="%F0%9F%92%A1-best-practices">💡 Best Practices</h2><ol><li><strong>Always specify both language and region</strong>, unless region truly doesn’t matter.</li><li><strong>Normalize tags</strong> to lowercase-uppercase (e.g., <code>en-GB</code>, not <code>en-gb</code>).</li><li>Use <strong>user preferences or browser headers</strong> to detect preferred locale.</li><li>When storing content per language, <strong>index by BCP 47 code</strong> (<code>en-GB</code>, <code>id-ID</code>, etc.)</li><li>Be careful with <strong>default fallbacks</strong>—don’t assume <code>en</code> means <code>en-US</code>.</li></ol><hr><h2 id="%F0%9F%93%9A-common-bcp-47-locale-codes">📚 Common BCP 47 Locale Codes</h2>
