<p>File management is a common task in software development, and Go provides an efficient way to work with directories and files. In this article, we'll explore how to create a Go program that <strong>lists all files in a directory</strong> along with their sizes. We'll also discuss <strong>key considerations</strong> and additional features you can implement to enhance the program.</p><h2 id="core-implementation-listing-files-and-their-sizes">Core Implementation: Listing Files and Their Sizes</h2><p>Here's a simple Go program to list files in a directory and display their names and sizes:</p><pre><code class="language-go">package main

import (
	"fmt"
	"log"
	"os"
)

func main() {
	// Specify the directory to scan
	directory := "./" // Change this to your desired directory path

	// Open the directory
	dir, err := os.Open(directory)
	if err != nil {
		log.Fatalf("Failed to open directory: %v", err)
	}
	defer dir.Close()

	// Read the directory contents
	files, err := dir.Readdir(-1)
	if err != nil {
		log.Fatalf("Failed to read directory: %v", err)
	}

	// Iterate through the files and display name and size
	fmt.Printf("Files in directory: %s\n", directory)
	for _, file := range files {
		if !file.IsDir() {
			fmt.Printf("Name: %s, Size: %d bytes\n", file.Name(), file.Size())
		}
	}
}
</code></pre><h3 id="key-points">Key Points</h3><ol><li><strong>Open the Directory</strong>: The <code>os.Open()</code> function is used to access the directory.</li><li><strong>Read Contents</strong>: The <code>Readdir(-1)</code> method reads all entries (files and directories) in the directory.</li><li><strong>Filter Files</strong>: Using <code>file.IsDir()</code>, we exclude directories from the output.</li><li><strong>Display Information</strong>: For each file, we print its name and size.</li></ol><div class="kg-card kg-callout-card kg-callout-card-blue"><div class="kg-callout-emoji">💡</div><div class="kg-callout-text">Live demo <a href="https://onecompiler.com/go/434nta9h7" rel="noreferrer">here</a>.</div></div><h2 id="enhancing-the-program-with-recursive-listing">Enhancing the Program with Recursive Listing</h2><p>If you want to list files in subdirectories as well, you can use the <code>path/filepath</code> package and the <code>Walk</code> function. Here’s the updated program:</p><pre><code class="language-go">package main

import (
	"fmt"
	"log"
	"os"
	"path/filepath"
)

func main() {
	// Specify the directory to scan
	directory := "./" // Change this to your desired directory path

	// Walk through the directory using filepath.Walk
	fmt.Printf("Files in directory: %s\n", directory)
	err := filepath.Walk(directory, func(path string, info os.FileInfo, err error) error {
		if err != nil {
			return err
		}
		// Check if it's a file
		if !info.IsDir() {
			fmt.Printf("Name: %s, Size: %d bytes\n", path, info.Size())
		}
		return nil
	})

	// Handle errors from filepath.Walk
	if err != nil {
		log.Fatalf("Error walking the directory: %v", err)
	}
}
</code></pre><h3 id="benefits-of-using-filepathwalk">Benefits of Using <code>filepath.Walk</code></h3><ul><li><strong>Recursive Scanning</strong>: It automatically traverses subdirectories.</li><li><strong>Full Path Access</strong>: Provides the full file path, making it easier to work with nested files.</li><li><strong>Error Handling</strong>: Handles errors gracefully for each file or directory.</li></ul><div class="kg-card kg-callout-card kg-callout-card-blue"><div class="kg-callout-emoji">💡</div><div class="kg-callout-text">Live demo <a href="https://onecompiler.com/go/434ntbhtv" rel="noreferrer">here</a>.</div></div><h2 id="additional-considerations">Additional Considerations</h2><h3 id="1-file-permissions">1. <strong>File Permissions</strong></h3><p>Ensure your program has the necessary permissions to read the directory and its contents.
