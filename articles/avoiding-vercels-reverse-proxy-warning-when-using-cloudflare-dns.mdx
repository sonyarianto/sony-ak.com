<p>If you’ve linked your <strong>custom domain</strong> to <strong>Vercel</strong> and manage your DNS through <strong>Cloudflare</strong>, you might see a warning in Vercel’s domain settings that says:</p><blockquote><em>"Your domain is behind a reverse proxy. This can limit Vercel's traffic visibility for security measures, introduce latency that degrades performance, and create cache management issues that may affect reliability."</em></blockquote><p>This issue happens because Cloudflare is <strong>proxying</strong> your domain instead of just resolving it as a regular DNS provider. Below, we’ll go over <strong>why this happens, how to fix it, and key considerations when using Cloudflare with Vercel</strong>.</p><hr><h3 id="%F0%9F%94%8D-why-does-this-happen">🔍 Why Does This Happen?</h3><p>Vercel expects to have <strong>direct access</strong> to your domain’s traffic to properly manage security, caching, and performance. When Cloudflare’s <strong>proxy mode (orange cloud ☁️)</strong> is enabled, it introduces a layer between visitors and Vercel’s servers. This leads to several potential issues:</p><ul><li><strong>Traffic visibility is reduced</strong> – Vercel may not see real client IPs, impacting security and analytics.</li><li><strong>Increased latency</strong> – Additional processing at Cloudflare before reaching Vercel.</li><li><strong>Caching conflicts</strong> – Cloudflare and Vercel both have their own caching systems, which can cause unpredictable behavior.</li><li><strong>Firewall and security settings</strong> – Cloudflare may block or rate-limit traffic that Vercel expects to receive.</li></ul><p>To avoid these problems, you need to properly configure Cloudflare and Vercel to work together.</p><hr><h3 id="%E2%9C%85-how-to-fix-the-warning">✅ How to Fix the Warning</h3><p>The best way to fix this issue depends on whether you want Cloudflare to only handle DNS or also act as a proxy.</p><h4 id="option-1-set-cloudflare-dns-to-%E2%80%9Cdns-only%E2%80%9D-recommended"><strong>Option 1: Set Cloudflare DNS to “DNS-only” (Recommended)</strong></h4><p>This option <strong>removes Cloudflare as a proxy</strong> while keeping it as your DNS provider.</p><ol><li><strong>Go to Cloudflare Dashboard</strong> → <strong>DNS Settings</strong>.</li><li>Find your <strong>CNAME record</strong> pointing to Vercel (<code>cname.vercel-dns.com</code>).</li><li>Click the <strong>orange cloud ☁️</strong> next to the record to turn it <strong>gray 🌑 (DNS-only)</strong>.</li><li>Save changes.</li></ol><p>This will resolve the Vercel warning while still allowing you to manage your domain with Cloudflare.</p><h4 id="option-2-keep-cloudflare-proxy-but-adjust-settings"><strong>Option 2: Keep Cloudflare Proxy but Adjust Settings</strong></h4><p>If you need Cloudflare’s proxy features (such as <strong>DDoS protection, WAF, or caching</strong>), you can try these adjustments:</p><ol><li><strong>Enable “True-Client-IP”</strong> – This passes the real client’s IP to Vercel instead of Cloudflare’s IP.</li><li><strong>Set “Cache Level” to “Bypass” for Vercel</strong> – Prevents Cloudflare from caching responses incorrectly.</li><li><strong>Disable “Orange-to-Orange” Redirects</strong> – Prevents conflict between Cloudflare and Vercel’s own proxy system.</li><li><strong>Check Cloudflare Firewall Rules</strong> – Ensure Cloudflare isn’t blocking Vercel’s automated traffic.</li><li><strong>Use Cloudflare Workers for Advanced Configuration</strong> – If needed, you can write a Worker script to forward traffic more efficiently.</li></ol><hr><h3 id="%E2%9A%A0%EF%B8%8F-additional-considerations">⚠️ Additional Considerations</h3><ul><li><strong>SSL Configuration</strong>: Vercel provides its own SSL certificates. If you keep Cloudflare proxy enabled, ensure the SSL mode is <strong>Full (Strict)</strong> to prevent security issues.</li><li><strong>Performance Impact</strong>: Adding Cloudflare as a proxy can slow down Vercel’s built-in optimizations, so test before deciding.</li><li><strong>Rate Limits &amp; Security Rules</strong>: Cloudflare may flag Vercel’s traffic as suspicious if too many requests are coming in quickly, so adjust security settings if needed.</li><li><strong>Edge Functions &amp; Middleware</strong>: If you’re using Vercel’s Edge Functions, Cloudflare’s additional layer may interfere with them.</li></ul><hr><h3 id="%F0%9F%8E%AF-final-recommendation">🎯 Final Recommendation</h3><p>If you are <strong>only using Cloudflare for DNS</strong>, switch your <strong>CNAME record to DNS-only</strong> (gray cloud 🌑). This will resolve the warning and ensure <strong>optimal performance</strong> with Vercel.</p><p>If you <strong>must use Cloudflare’s proxy features</strong>, make sure you properly configure your settings to avoid conflicts with Vercel’s own infrastructure.</p><p>By making these changes, you can ensure <strong>a smooth integration between Cloudflare and Vercel without impacting performance or reliability</strong>.</p><h3 id="support-us">Support Us</h3>
