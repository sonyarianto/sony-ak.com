<p>Go is known for its simplicity and strict adherence to readability, but sometimes that simplicity can require verbose code. In Go, <strong>syntactic sugar</strong> is rare, yet occasionally, small enhancements can improve readability without sacrificing Go's core principles. One such enhancement is a utility like <code>cmp.Or</code>, which can elegantly <strong>eliminate <code>if-else</code> statements</strong> in certain scenarios, helping make code shorter and clearer.</p><p>In this article, we'll dive into the <code>cmp.Or</code> function, discuss <strong>its benefits, use cases</strong>, and explore situations where you might consider using it.</p><h3 id="what-is-cmpor">What is <code>cmp.Or</code>?</h3><p>The <code>cmp.Or</code> function, a <strong>custom utility function</strong>, takes a variable number of arguments and returns the <strong>first non-zero (non-default)</strong> value among them. For Go developers, this is like a <strong>shortcut</strong> to replace conditional logic in cases where you'd typically return the first available value that meets a condition.</p><h3 id="the-code">The Code</h3><p>Here’s an example implementation of <code>cmp.Or</code>:</p><pre><code>package cmp

// Or takes an arbitrary number of values and returns the first non-zero (non-default) value.
func Or[T comparable](values ...T) T {
	var zero T
	for _, v := range values {
		if v != zero {
			return v
		}
	}
	return zero
}
</code></pre><p><strong>What does this code do?</strong> It iterates through a list of values and <strong>returns the first non-zero element</strong> it encounters. If all values are zero, it returns zero (or the default) of that type. This utility can work with any type that is <strong>comparable and has a default value</strong>, like numbers, strings, pointers, and structs with comparable fields.</p><h3 id="how-to-use-cmpor-in-your-code">How to Use <code>cmp.Or</code> in Your Code</h3><p>With <code>cmp.Or</code>, you can skip verbose <code>if-else</code> chains when you're selecting the first valid option. Here’s an example:</p><pre><code>package main

import (
	"fmt"
	"cmp"
)

func main() {
	a := 0
	b := 5
	c := 10

	// Using cmp.Or to find the first non-zero value
	result := cmp.Or(a, b, c)
	fmt.Println(result) // Output: 5
}
</code></pre><p>In this example, <code>cmp.Or</code> returns <code>5</code>, which is the first non-zero value in the sequence. Without <code>cmp.Or</code>, you’d need to write a series of <code>if</code> checks, making the code more verbose.</p><div class="kg-card kg-callout-card kg-callout-card-blue"><div class="kg-callout-emoji">💡</div><div class="kg-callout-text">Live demo <a href="https://onecompiler.com/go/42y33kkqv" rel="noreferrer">here</a>.</div></div><h3 id="why-use-cmpor">Why Use <code>cmp.Or</code>?</h3><p>The <strong>advantages</strong> of using <code>cmp.Or</code> go beyond just saving a few lines of code. Here are some other reasons why it’s worth considering:</p><ul><li><strong>Improved Readability</strong>: Nested <code>if-else</code> blocks can be hard to read, especially when dealing with fallback values. <code>cmp.Or</code> is explicit in its purpose—getting the first valid option.</li><li><strong>Less Error-Prone</strong>: It’s easy to make mistakes in complex conditional chains. <code>cmp.Or</code> centralizes the logic, reducing the chance of a typo or oversight in multiple <code>if</code> statements.</li><li><strong>More Idiomatic Go Code</strong>: Although it may initially look like a non-Go-like approach, <code>cmp.Or</code> aligns with <strong>Go’s preference for clear and concise code</strong> while maintaining simplicity.</li></ul><h3 id="considerations-and-limitations">Considerations and Limitations</h3><p>While <code>cmp.Or</code> is a powerful utility, <strong>consider these factors</strong> when deciding whether to use it:</p><ol><li><strong>Type Compatibility</strong>: <code>cmp.Or</code> only works with types that have a meaningful zero value. It won’t work with slices, maps, or interfaces that lack a zero concept in the same way integers or strings do.</li><li><strong>Clarity for Non-Go Developers</strong>: Go’s explicit nature means that sometimes <code>if-else</code> statements are preferable, especially for developers new to Go. When using <code>cmp.Or</code>, ensure the intention is clear.</li><li><strong>Use in Critical Sections</strong>: If used inside performance-critical code, be mindful of the function’s overhead. While generally minor, iterating through many arguments can slightly affect performance.</li><li><strong>Only for Short Fallback Chains</strong>: <code>cmp.Or</code> is best suited for short lists of values. If there are complex or dynamic fallback criteria, it’s better to write explicit conditional logic to avoid confusion.</li></ol><h3 id="other-use-cases-and-ideas">Other Use Cases and Ideas</h3><p><code>cmp.Or</code> is primarily useful for fallback values, but here are a few other scenarios where it can shine:</p><ul><li><strong>Database Defaults</strong>: If you have values from a database query where some fields may be missing, use <code>cmp.Or</code> to set sensible defaults without extra checks.</li><li><strong>Configuration Management</strong>: When managing configurations with optional parameters, <code>cmp.Or</code> allows you to quickly select a parameter’s value or use a default.</li><li><strong>Environment Variables</strong>: When checking environment variables with possible fallbacks, <code>cmp.Or</code> can streamline the code by removing the need for repeated <code>if-else</code> checks.</li></ul><h3 id="finally">Finally</h3><p><code>cmp.Or</code> provides a <strong>clean, readable alternative to <code>if-else</code> chains</strong>, allowing Go developers to achieve concise code without sacrificing clarity. While syntactic sugar in Go is rare, this function strikes a nice balance, adding simplicity without straying from Go’s core principles. Whether for handling fallback values, configuring defaults, or improving code readability, <code>cmp.Or</code> is a handy utility worth adding to your toolkit.</p><p>In Go, where <strong>simplicity is the ultimate sophistication</strong>, <code>cmp.Or</code> is a small yet impactful tool that helps developers write clear, maintainable code.
