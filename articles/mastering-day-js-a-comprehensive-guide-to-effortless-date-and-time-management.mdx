<p>When working with JavaScript, handling dates and times can be tricky. That’s where <strong>Day.js</strong>, a minimalist JavaScript library, comes to the rescue. It provides a simple, clean, and consistent API for manipulating and formatting dates without the overhead of larger libraries like Moment.js. In this article, we’ll explore the <strong>core features of Day.js</strong> and add a few more tips to level up your date-handling skills.</p><p>First import it.</p><pre><code class="language-js">const dayjs = require("dayjs");</code></pre><h2 id="1-creating-dates-made-simple"><strong>1. Creating Dates Made Simple</strong></h2><p>Day.js makes creating dates intuitive:</p><ul><li><code>dayjs()</code> gives you the <strong>current date and time</strong>.</li><li>You can also create specific dates: <code>dayjs('2024-09-19')</code>.</li><li>Specify both date and time: <code>dayjs('2024-09-19 12:00:00')</code>.</li></ul><p>This functionality ensures a seamless way to initialize your dates.</p><h2 id="2-effortless-date-formatting"><strong>2. Effortless Date Formatting</strong></h2><p>Formatting dates is one of the most commonly used features:</p><ul><li><code>dayjs().format()</code> provides the <strong>default ISO format</strong>.</li><li>Customize your formats:</li></ul><pre><code class="language-js">dayjs().format('YYYY-MM-DD') // 2024-09-19
dayjs().format('DD/MM/YYYY') // 19/09/2024
dayjs().format('HH:mm:ss') // 12:00:00
</code></pre><p>These flexible formats cater to various date representations.</p><h2 id="3-parsing-and-displaying-dates"><strong>3. Parsing and Displaying Dates</strong></h2><p>Day.js makes parsed dates <strong>human-readable</strong>:</p><pre><code class="language-js">dayjs('2024-09-19').format('MMMM D, YYYY'); // September 19, 2024
</code></pre><p>This ensures clarity when dealing with date outputs in different formats.</p><h2 id="4-manipulating-dates-with-ease"><strong>4. Manipulating Dates with Ease</strong></h2><p>Modifying dates is straightforward:</p><ul><li>Add or subtract time:</li></ul><pre><code class="language-js">dayjs().add(1, 'day'); // Adds 1 day
dayjs().subtract(1, 'month'); // Subtracts 1 month
</code></pre><ul><li>Find the <strong>start or end</strong> of a specific time period:</li></ul><pre><code class="language-js">dayjs().startOf('month'); // Start of the month
dayjs().endOf('year'); // End of the year
</code></pre><p>These methods simplify date adjustments without complex calculations.</p><h2 id="5-comparing-dates"><strong>5. Comparing Dates</strong></h2><p>Day.js provides intuitive methods for comparisons:</p><ul><li>Check if a date is before or after today:</li></ul><pre><code class="language-js">dayjs('2024-09-19').isBefore(dayjs()); // true or false
dayjs('2024-09-19').isAfter(dayjs()); // true or false
</code></pre><ul><li>Verify if two dates are identical:</li></ul><pre><code class="language-js">dayjs('2024-09-19').isSame('2024-09-19'); // true
</code></pre><p>These methods are essential for validating time-sensitive conditions.</p><h2 id="6-calculating-date-differences"><strong>6. Calculating Date Differences</strong></h2><p>Need to measure time spans? Day.js has you covered:</p><ul><li>Calculate differences in years, days, or other units:</li></ul><pre><code class="language-js">dayjs('2024-09-19').diff(dayjs('2023-09-19'), 'year'); // 1
dayjs('2024-09-19').diff(dayjs(), 'day'); // Number of days
</code></pre><p>This makes Day.js perfect for duration calculations.</p><h2 id="7-working-with-time"><strong>7. Working with Time</strong></h2><p>Access individual time components:</p><ul><li>Get the current hour: <code>dayjs().hour()</code></li><li>Get the current minute: <code>dayjs().minute()</code></li><li>Get the current second: <code>dayjs().second()</code></li></ul><p>This granularity is ideal for real-time applications.</p><h2 id="8-extracting-date-parts"><strong>8. Extracting Date Parts</strong></h2><p>Breaking down a date is simple:</p><ul><li>Year: <code>dayjs().year()</code> // 2024</li><li>Month: <code>dayjs().month()</code> // 8 (September, 0-indexed)</li><li>Day of the month: <code>dayjs().date()</code> // 19</li></ul><p>Day.js helps disassemble a date for detailed analysis.</p><h2 id="9-handling-utc-dates"><strong>9. Handling UTC Dates</strong></h2><p>Timezones can be challenging, but Day.js supports <strong>UTC manipulation</strong>:</p><ul><li>Current UTC date: <code>dayjs().utc().format()</code></li><li>Set a specific UTC offset: <code>dayjs().utcOffset(0).format()</code></li></ul><p>This ensures consistency across global applications.</p><h2 id="10-durations-and-time-between-dates"><strong>10. Durations and Time Between Dates</strong></h2><p>Day.js offers robust duration handling:</p><ul><li>1-day duration: <code>dayjs.duration(1, 'day')</code></li><li>Convert 2 hours to minutes:</li></ul><pre><code class="language-js">dayjs.duration(2, 'hours').asMinutes(); // 120 minutes
</code></pre><p>This simplifies working with time intervals.</p><h2 id="11-relative-time"><strong>11. Relative Time</strong></h2><p>Expressing dates relatively is intuitive:</p><pre><code class="language-js">dayjs().to('2024-09-19'); // in 1 day
dayjs().from('2023-09-19'); // 1 year ago
</code></pre><p>Relative time makes dynamic date displays easier to manage.</p><h2 id="additional-tips-and-considerations"><strong>Additional Tips and Considerations</strong></h2><h3 id="localization"><strong>Localization</strong></h3><p>Day.js supports multiple languages out of the box. Import the required locale:</p><pre><code class="language-js">const dayjs = require('dayjs');
const locale = require('dayjs/locale/fr'); // French
dayjs.locale('fr');
console.log(dayjs().format('dddd, MMMM D, YYYY')); // Displays in French
</code></pre><h3 id="custom-plugins"><strong>Custom Plugins</strong></h3><p>Enhance functionality using plugins:</p><ul><li><code>duration</code>: For advanced time manipulation.</li><li><code>advancedFormat</code>: For complex date formatting.</li><li>Install plugins:</li></ul><pre><code class="language-js">const relativeTime = require('dayjs/plugin/relativeTime');
dayjs.extend(relativeTime);
</code></pre><h3 id="performance"><strong>Performance</strong></h3><p>Day.js is lightweight (2kB) and immutable, making it ideal for high-performance applications without the bulk of larger libraries.</p><h2 id="finally"><strong>Finally</strong></h2><p>Day.js is a powerful, lightweight alternative for handling dates and times in JavaScript. Its intuitive API, rich plugin ecosystem, and flexibility make it a must-have tool for any developer. With the tips and methods shared in this guide, you’re now equipped to handle all your date-related challenges effectively.</p><h3 id="support-us">Support Us</h3>
