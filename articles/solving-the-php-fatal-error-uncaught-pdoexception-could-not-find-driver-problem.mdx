<p>When building modern PHP applications—especially those using frameworks like <strong>Laravel</strong>, <strong>Symfony</strong>, or any project that connects to a database using <strong>PDO (PHP Data Objects)</strong>—you might encounter a frustrating error like this:</p><pre><code>PHP Fatal error:  Uncaught PDOException: could not find driver
</code></pre><p>This error often happens during local development, Docker builds, or fresh deployments. But what exactly does it mean, and how do you fix it?</p><hr><h3 id="understanding-the-error"><strong>Understanding the Error</strong></h3><p>The message <code>could not find driver</code> is not referring to a missing database like MySQL or PostgreSQL—but to a missing <strong>PDO database driver</strong> that PHP uses to communicate with your database.</p><p>For example:</p><ul><li>If you're using <strong>MySQL</strong>, PHP needs the <code>pdo_mysql</code> extension.</li><li>If you're using <strong>PostgreSQL</strong>, PHP needs the <code>pdo_pgsql</code> extension.</li></ul><p>If these extensions are missing or not loaded, PHP can’t create a PDO connection, and your application crashes.</p><hr><h3 id="common-scenarios-where-this-happens"><strong>Common Scenarios Where This Happens</strong></h3><ul><li>You installed <strong>PHP</strong> but didn’t install the matching <strong>PDO driver</strong>.</li><li>You're running <strong>PHP in a Docker container</strong> but forgot to include the necessary extension in your Dockerfile.</li><li>You switched to a different version of PHP (e.g. PHP 8.x) but forgot to reinstall or re-enable the extensions.</li><li>The extension is present, but not <strong>enabled</strong> in your <code>php.ini</code>.</li></ul><hr><h3 id="how-to-fix-it"><strong>How to Fix It</strong></h3><h4 id="%E2%9C%85-1-install-the-required-php-extension">✅ <strong>1. Install the Required PHP Extension</strong></h4><p>Choose the one that matches your database:</p><p><strong>For MySQL / MariaDB</strong>:</p><pre><code class="language-bash"># Ubuntu/Debian
sudo apt install php-mysql

# Alpine (commonly used in Docker)
apk add php-pdo_mysql
</code></pre><p><strong>For PostgreSQL</strong>:</p><pre><code class="language-bash"># Ubuntu/Debian
sudo apt install php-pgsql

# Alpine
apk add php-pdo_pgsql
</code></pre><hr><h4 id="%E2%9C%85-2-restart-your-web-server">✅ <strong>2. Restart Your Web Server</strong></h4><p>After installation, make sure to restart your PHP service:</p><pre><code class="language-bash">sudo systemctl restart apache2
# or if you're using Nginx:
sudo systemctl restart php8.2-fpm
</code></pre><hr><h4 id="%E2%9C%85-3-check-if-the-extension-is-enabled">✅ <strong>3. Check if the Extension is Enabled</strong></h4><p>Run:</p><pre><code class="language-bash">php -m | grep pdo
</code></pre><p>Expected output:</p><pre><code>PDO
pdo_mysql
</code></pre><p>If nothing shows up, make sure the extensions are enabled in your <code>php.ini</code>. Look for these lines and <strong>ensure they are not commented out</strong> (remove the <code>;</code>):</p><pre><code class="language-ini">extension=pdo_mysql
</code></pre><p>Then restart the server again.</p><hr><h3 id="how-to-avoid-this-in-the-future"><strong>How to Avoid This in the Future</strong></h3><ul><li><strong>Use <code>phpinfo()</code> or <code>php -i</code></strong> to inspect your running PHP configuration.</li><li>If you’re using <strong>Docker</strong>, always <strong>explicitly install extensions</strong> in your Dockerfile.</li><li>In Laravel apps, this often happens during CI/CD. Your CI job should <strong>install dependencies, PHP extensions, and run <code>php artisan config:cache</code></strong> properly.</li><li>Consider using tools like <strong>Laravel Sail</strong> or <strong>Laragon</strong> (Windows) that come pre-configured.</li></ul><hr><h3 id="bonus-tip-how-to-check-which-db-driver-laravel-is-using"><strong>Bonus Tip: How to Check Which DB Driver Laravel is Using</strong></h3><p>If you're unsure which driver Laravel is trying to use, open your <code>.env</code> file:</p><pre><code>DB_CONNECTION=mysql
</code></pre><p>Then, in <code>config/database.php</code>, Laravel maps this to a PDO driver:</p><pre><code class="language-php">'mysql' =&gt; [
    'driver' =&gt; 'mysql',
    ...
]
</code></pre><p>So in this case, Laravel will need <code>pdo_mysql</code>.</p><hr><h3 id="finally"><strong>Finally</strong></h3><p>This error—<strong>"could not find driver"</strong>—has nothing to do with your actual database credentials. It’s purely a PHP-level problem caused by <strong>missing extensions</strong>. The good news? It’s very easy to fix once you know what’s missing.</p><p>Make sure the <strong>PDO extension for your specific database is installed and loaded</strong>, and the error will disappear.</p><p><strong>Still stuck?</strong> Try running <code>php -i | grep "Loaded Configuration File"</code> to see which <code>php.ini</code> file is being used, and check if the extensions are enabled there.</p><h3 id="support-us">Support Us</h3>
