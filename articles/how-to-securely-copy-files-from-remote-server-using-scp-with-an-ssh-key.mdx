<p>When working with remote servers, transferring files back and forth is a common task. One of the simplest ways to <strong>securely download files</strong> from a remote machine is using the <code>scp</code> command — a tool that comes with the <strong>OpenSSH</strong> suite and works on <strong>Windows, Linux, and macOS</strong>.</p><hr><h3 id="%E2%9C%85-what-is-scp">✅ <strong>What is <code>scp</code>?</strong></h3><p><code>scp</code> stands for <strong>secure copy</strong>. It’s a command-line tool that lets you <strong>transfer files over SSH</strong>, meaning your data stays <strong>encrypted</strong> and secure during transmission.</p><hr><h3 id="%F0%9F%94%91-using-scp-with-an-identity-file">🔑 <strong>Using <code>scp</code> with an Identity File</strong></h3><p>If your server uses <strong>key-based authentication</strong> (instead of a password), you’ll need to specify the path to your <strong>private key</strong> with the <code>-i</code> option.</p><h4 id="basic-syntax"><strong>Basic Syntax</strong>:</h4><pre><code class="language-bash">scp -i /path/to/private_key username@remote_host:/path/to/remote/file /path/to/local/destination
</code></pre><h4 id="example"><strong>Example</strong>:</h4><pre><code class="language-bash">scp -i ~/.ssh/id_rsa user@192.168.1.10:/home/user/file.txt .
</code></pre><blockquote>This command will download <code>file.txt</code> to your <strong>current directory</strong> (<code>.</code>).</blockquote><hr><h3 id="%F0%9F%93%81-copying-a-whole-directory">📁 <strong>Copying a Whole Directory</strong></h3><p>To copy an entire folder (including its contents), add the <code>-r</code> flag:</p><pre><code class="language-bash">scp -i ~/.ssh/id_rsa -r user@192.168.1.10:/home/user/myfolder .
</code></pre><p>This recursively downloads everything inside <code>myfolder</code>.</p><hr><h3 id="%F0%9F%A7%AD-save-to-a-specific-path-or-rename-file">🧭 <strong>Save to a Specific Path or Rename File</strong></h3><p>You’re not limited to saving in the current folder. For example:</p><pre><code class="language-bash">scp -i ~/.ssh/id_rsa user@192.168.1.10:/home/user/file.txt C:/Users/YourName/Documents/newname.txt
</code></pre><blockquote>This renames <code>file.txt</code> to <code>newname.txt</code> and saves it into your Documents folder on <strong>Windows</strong>.</blockquote><hr><h3 id="%F0%9F%94%81-custom-ssh-port">🔁 <strong>Custom SSH Port</strong></h3><p>If the server uses a non-standard SSH port (not 22), add <code>-P</code> (uppercase):</p><pre><code class="language-bash">scp -i ~/.ssh/id_rsa -P 2222 user@192.168.1.10:/home/user/file.txt .
</code></pre><hr><h3 id="%F0%9F%92%A1-helpful-tips-and-considerations">💡 <strong>Helpful Tips and Considerations</strong></h3><ul><li><strong>Use absolute paths</strong> for remote files to avoid confusion.</li><li>Make sure the <strong>private key file</strong> is not publicly readable (on Linux/macOS: <code>chmod 600</code>).</li><li>On Windows, use <code>scp</code> either via:<ul><li><strong>Command Prompt or PowerShell</strong> (after installing the <strong>OpenSSH Client</strong>).</li><li>Or via <strong>WSL (Windows Subsystem for Linux)</strong> for a more UNIX-like experience.</li></ul></li><li>If you're using WSL, remember that file paths follow <strong>Linux format</strong> (e.g., <code>/mnt/c/Users/...</code>).</li></ul><hr><h3 id="%F0%9F%9A%80-speeding-things-up-with-ssh-config-optional">🚀 <strong>Speeding Things Up with SSH Config (Optional)</strong></h3><p>If you connect to the same server frequently, you can create a config entry in <code>~/.ssh/config</code> (Linux/macOS/WSL):</p><pre><code class="language-ini">Host myserver
    HostName 192.168.1.10
    User user
    IdentityFile ~/.ssh/id_rsa
    Port 2222
</code></pre><p>Then, instead of the full command, just use:</p><pre><code class="language-bash">scp myserver:/home/user/file.txt .
</code></pre><p>Much faster.</p><hr><h3 id="%F0%9F%A7%B1-why-scp-over-other-tools">🧱 <strong>Why <code>scp</code> Over Other Tools?</strong></h3><ul><li>No need for GUI.</li><li>Works from <strong>any shell</strong>.</li><li>Easier to <strong>script or automate</strong>.</li><li>Uses <strong>standard SSH ports and credentials</strong>.</li></ul><p>If you prefer a GUI tool, you might also look at <strong>WinSCP (Windows)</strong> or <strong>Cyberduck (macOS)</strong>, which offer similar functionality but with drag-and-drop convenience.</p><hr><h3 id="%F0%9F%93%8C-final-thoughts">📌 Final Thoughts</h3><p>The <code>scp</code> command is a fast, secure, and reliable way to copy files over SSH. Whether you’re on Windows, Linux, or macOS, the command works the same — especially powerful when using <strong>SSH key authentication</strong>.</p><p>Next time you need to pull logs, backups, or deployment assets, remember this simple one-liner:</p><pre><code class="language-bash">scp -i /path/to/key user@host:/remote/file .
</code></pre><p>Fast, clean, secure.</p><h3 id="support-us">Support Us</h3>
