<h3 id="problem">Problem:</h3><p>When I type <code>sudo do-release-upgrade</code> there is error like this.</p><pre><code>Checking for a new Ubuntu release
In /etc/update-manager/release-upgrades Prompt
is set to never so upgrading is not possible.</code></pre><h3 id="solution">Solution:</h3><p>The message you're seeing indicates that your system's configuration is preventing the release upgrade due to the setting in the <code>/etc/update-manager/release-upgrades</code> file. Here’s how to resolve this issue:</p><ol><li><strong>Open the configuration file</strong>: You need to edit the <code>release-upgrades</code> configuration file. You can use a text editor like <code>nano</code> or <code>vim</code>. For example, using <code>nano</code>:</li></ol><pre><code class="language-bash">sudo nano /etc/update-manager/release-upgrades
</code></pre><ol start="2"><li><strong>Change the Prompt setting</strong>: Look for the line that starts with <code>Prompt=</code>. It may look like this:</li></ol><pre><code class="language-bash">Prompt=never
</code></pre><p>Change <code>never</code> to either <code>lts</code> (if you only want to upgrade to the next Long Term Support version) or <code>normal</code> (to upgrade to any new release).</p><ol start="3"><li><strong>Save the changes</strong></li><li><strong>Run the upgrade command again</strong>: <code>sudo do-release-upgrade</code></li></ol><p>This should allow you to check for and proceed with the Ubuntu release upgrade.
