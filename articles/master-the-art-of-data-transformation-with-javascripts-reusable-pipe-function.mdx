<p>In the world of JavaScript, one of the most <strong>underrated yet powerful concepts</strong> is the <strong>pipe function</strong>. It provides an elegant way to create <strong>reusable, modular, and composable transformations</strong> that can simplify your code while improving readability and maintainability. If you're not familiar with this technique, you're missing out on a handy tool in your programming arsenal!</p><p>Let's dive into what a <strong>pipe function</strong> is, how it works, and why you should start using it today.</p><h3 id="what-is-a-pipe-function"><strong>What Is a Pipe Function?</strong></h3><p>At its core, a <strong>pipe function</strong> is a utility that allows you to <strong>compose multiple functions into a single operation</strong>. Think of it as a pipeline where data flows through a series of transformations, step by step, in a well-defined order.</p><p>Here’s a simple implementation of a pipe function in JavaScript:</p><pre><code class="language-javascript">const pipe = (...fns) =&gt; (arg) =&gt; fns.reduce((value, fn) =&gt; fn(value), arg);
</code></pre><ul><li>The <code>pipe</code> function takes a <strong>list of functions</strong> (<code>...fns</code>) as arguments.</li><li>It returns a <strong>new function</strong> that takes a value (<code>arg</code>) and applies the functions <strong>in sequence</strong> using <code>reduce</code>.</li><li>Each function in the pipeline <strong>receives the output</strong> of the previous function as its input.</li></ul><h3 id="how-to-use-the-pipe-function"><strong>How to Use the Pipe Function?</strong></h3><p>Let’s look at an example of how you can use the <code>pipe</code> function to calculate profit based on a series of business rules:</p><pre><code class="language-javascript">const calculateProfit = pipe(
  value =&gt; value * (1 - 0.08), // Deduct VAT (8%)
  value =&gt; value * (1 - 0.15), // Deduct tax (15%)
  value =&gt; value + 2500,       // Add external contributions
  value =&gt; value / 3           // Split with co-founders
);

const revenue = 50_000;
const profit = calculateProfit(revenue);
console.log(profit); // Output: transformed profit
</code></pre><p>Here’s what’s happening step-by-step:</p><ol><li><strong>Deduct VAT</strong>: The revenue is reduced by 8%.</li><li><strong>Deduct Tax</strong>: Another 15% is deducted from the remaining amount.</li><li><strong>Add Contributions</strong>: A fixed amount of 2,500 is added.</li><li><strong>Split Shares</strong>: The final amount is divided among three co-founders.</li></ol><h3 id="why-use-the-pipe-function"><strong>Why Use the Pipe Function?</strong></h3><p><strong>1. Modularity</strong><br>Each transformation step is an <strong>independent function</strong>. This makes your code easier to read, test, and maintain.</p><p><strong>2. Reusability</strong><br>Individual functions can be reused in other pipelines, saving time and reducing redundancy.</p><p><strong>3. Readability</strong><br>The pipeline structure mirrors how you naturally think about the problem: <strong>"first do this, then that, and finally this."</strong></p><p><strong>4. Scalability</strong><br>Adding new steps to the pipeline is as simple as appending another function to the pipe.</p><h3 id="additional-considerations"><strong>Additional Considerations</strong></h3><h4 id="error-handling"><strong>Error Handling</strong></h4><p>In a real-world application, not every transformation will succeed. <strong>What happens if one function throws an error?</strong> To handle this, you can extend the pipe to include error handling, like this:</p><pre><code class="language-javascript">const safePipe = (...fns) =&gt; (arg) =&gt; {
  try {
    return fns.reduce((value, fn) =&gt; fn(value), arg);
  } catch (err) {
    console.error("Pipeline error:", err);
    return null; // or a default value
  }
};
</code></pre><h4 id="asynchronous-functions"><strong>Asynchronous Functions</strong></h4><p>What if one or more transformations involve asynchronous operations, such as fetching data from an API? For this, you’ll need an <strong>async-compatible pipe function</strong>:</p><pre><code class="language-javascript">const asyncPipe = (...fns) =&gt; (arg) =&gt;
  fns.reduce((promise, fn) =&gt; promise.then(fn), Promise.resolve(arg));

// Example usage
const fetchData = async (value) =&gt; {
  const response = await fetch(`https://api.example.com/data/${value}`);
  return response.json();
};

const asyncPipeline = asyncPipe(
  fetchData,
  data =&gt; data.filter(item =&gt; item.active),
  filteredData =&gt; filteredData.length
);

asyncPipeline(123).then(console.log); // Logs the count of active items
</code></pre><h4 id="performance-considerations"><strong>Performance Considerations</strong></h4><p>While <code>pipe</code> is incredibly flexible, chaining too many functions can introduce performance bottlenecks, especially for large datasets. In such cases, consider optimizing your transformations by batching operations or simplifying logic.</p><h3 id="bonus-the-pipe-function-vs-compose-function"><strong>Bonus: The Pipe Function vs Compose Function</strong></h3><p>If you’ve worked with functional programming libraries like <strong>Lodash</strong> or <strong>Ramda</strong>, you may have encountered the <code>compose</code> function, which works similarly to <code>pipe</code>.</p><p>The difference lies in the <strong>order of execution</strong>:</p><ul><li><code>pipe</code>: Executes functions <strong>left-to-right</strong> (more natural for most people).</li><li><code>compose</code>: Executes functions <strong>right-to-left</strong> (common in mathematical notation).</li></ul><p>Example using <code>compose</code>:</p><pre><code class="language-javascript">const compose = (...fns) =&gt; (arg) =&gt; fns.reduceRight((value, fn) =&gt; fn(value), arg);

const calculateProfit = compose(
  value =&gt; value / 3,
  value =&gt; value + 2500,
  value =&gt; value * (1 - 0.15),
  value =&gt; value * (1 - 0.08)
);
</code></pre><p>Both approaches are valid, but many developers prefer <code>pipe</code> for its readability.</p><figure class="kg-card kg-embed-card"><blockquote class="twitter-tweet"><p lang="en" dir="ltr">Here's an example of how you can create a reusable and composable pipe using JavaScript. <a href="https://t.co/FcRpHfxKdG">pic.twitter.com/FcRpHfxKdG</a></p>— Simon Høiberg (@SimonHoiberg) <a href="https://twitter.com/SimonHoiberg/status/1438766452446793733?ref_src=twsrc%5Etfw">September 17, 2021</a></blockquote>
