<p>When learning Python loops, one of the most common questions beginners ask is:<br>“<strong>Why do I need to put 7 in <code>range(1, 7)</code> just to print numbers from 1 to 6?</strong>”</p><p>The answer lies in how <strong>Python’s <code>range()</code> function</strong> is designed. Let’s break it down thoroughly, so you can not only use it but also remember the reasoning behind it.</p><hr><h2 id="the-basics-of-range">The Basics of <code>range()</code></h2><p>The <code>range()</code> function generates a sequence of numbers. Its full signature is:</p><pre><code class="language-python">range(start, stop, step)
</code></pre><ul><li><code><strong>start</strong></code> → the first number in the sequence (default is <code>0</code>).</li><li><strong><code>stop</code></strong> → the number where the sequence <strong>ends, but not included</strong>.</li><li><code><strong>step</strong></code> → the difference between each number (default is <code>1</code>).</li></ul><p>So:</p><pre><code class="language-python">for i in range(1, 7):
    print(i)
</code></pre><p>produces:</p><pre><code>1
2
3
4
5
6
</code></pre><p>Notice that <strong>7 is excluded</strong>. That’s why it feels like you’re writing <code>n+1</code>.</p><hr><h2 id="why-does-python-exclude-the-stop-value">Why Does Python Exclude the Stop Value?</h2><p>This design is not an accident. Python (like many other programming languages) uses <strong>half-open intervals</strong> <code>[start, stop)</code>. That means:</p><ul><li>The sequence <strong>includes the start</strong>.</li><li>The sequence <strong>excludes the stop</strong>.</li></ul><p>This has several <strong>practical benefits</strong>:</p><ol><li><strong>Length is easy to compute</strong><br>The number of items in <code>range(start, stop)</code> is simply <code>stop - start</code>.<br>Example: <code>range(1, 7)</code> → length = <code>7 - 1 = 6</code>.</li></ol><p><strong>Simplicity in loops</strong><br>If you want to loop through all items in a list:</p><pre><code class="language-python">for i in range(len(nums)):
    print(nums[i])
</code></pre><p>You don’t need to write <code>len(nums) - 1</code>. The exclusion of <code>stop</code> makes the loop clean.</p><p><strong>Consistency with indexing</strong><br>Lists, strings, and other sequences in Python use the same half-open style.<br>For example:</p><pre><code class="language-python">nums = [10, 20, 30, 40, 50]
print(nums[1:3])  # [20, 30]
</code></pre><p>Index <code>1</code> is included, but index <code>3</code> is excluded.</p><hr><h2 id="common-pitfall-thinking-of-stop-as-%E2%80%9Cthe-last-number%E2%80%9D">Common Pitfall: Thinking of Stop as “the Last Number”</h2><p>A lot of confusion happens when people assume <code>stop</code> means <strong>“the last number I want.”</strong><br>Instead, it’s better to think of <code>stop</code> as <strong>“where you stop counting.”</strong></p><p>So if you want numbers from <code>1</code> to <code>n</code>, you must write:</p><pre><code class="language-python">for i in range(1, n + 1):
    print(i)
</code></pre><p>That extra <code>+1</code> is natural once you remember that <strong><code>stop</code> is excluded.</strong></p><hr><h2 id="using-step-for-more-control">Using <code>step</code> for More Control</h2><p>Don’t forget the third parameter: <strong><code>step</code></strong>.</p><p>Examples:</p><pre><code class="language-python"># Count by 2
for i in range(1, 10, 2):
    print(i)
# 1, 3, 5, 7, 9

# Count backwards
for i in range(5, 0, -1):
    print(i)
# 5, 4, 3, 2, 1
</code></pre><p>The <code>step</code> value gives you flexibility beyond just sequential counting.</p><hr><h2 id="other-considerations">Other Considerations</h2><p><strong>Negative ranges</strong><br>You can use negative numbers too:</p><pre><code class="language-python">for i in range(-3, 2):
    print(i)
# -3, -2, -1, 0, 1
</code></pre><p><strong>Convert to list if needed</strong><br>If you want to see the actual sequence:</p><pre><code class="language-python">print(list(range(1, 7)))
# [1, 2, 3, 4, 5, 6]
</code></pre><p><strong>Large ranges are lazy</strong><br><code>range()</code> doesn’t create a full list in memory. Instead, it generates numbers on the fly, making it memory-efficient even for huge ranges:</p><pre><code class="language-python">big_range = range(1, 10_000_000)
print(len(big_range))  # 9999999
</code></pre><hr><h2 id="finally">Finally</h2><p>The rule to remember is simple:</p><ul><li><strong>Start is included.</strong></li><li><strong>Stop is excluded.</strong></li><li><strong>Step controls the jump.</strong></li></ul><p>So when you write:</p><pre><code class="language-python">for i in range(1, 7):
    print("Number:", i)
</code></pre><p>you’re really saying:<br><strong>“Start at 1, keep going up by 1, but stop before you reach 7.”</strong></p><p>That’s why programmers often think of the stop value as <code><strong>n+1</strong></code> when they want to include <code>n</code> in the loop.</p><hr><p>✅ <strong>Key takeaway:</strong> Always treat <code>stop</code> as the <em>boundary</em> rather than the <em>last number</em>. This mindset will make Python loops and slicing much easier to understand and use.</p><h3 id="support-us">Support Us</h3>
